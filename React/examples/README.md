# React examples

Поделитесь примерами кода на React, которые решают какую-то нетривиальную задачу или красиво и эффективно решают простые задачи.

- [Infinite Scroll](https://codesandbox.io/p/sandbox/77pwqs) - простой пример как сделать эффект бесконечного скролла используя хук `useInView` из `react-intersection-observer`. Если вам нужен бесконечный скролл в паре с `tanstack/react-query`, вам [сюда](https://tanstack.com/query/latest/docs/framework/react/examples/load-more-infinite-scroll).
