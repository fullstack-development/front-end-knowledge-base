# Полезные ресурсы для Frontend

Здесь можно делиться общими полезными ресурсами.

### Fake REST API
 - [dummy JSON](https://dummyjson.com/) - бесплатное REST API с кучей фейковых данных. Есть картинки, поддерживает POST, PUT, DELETE (имитирует, но не меняет состояние на сервере). 

### SVG
  - [SVG repo](https://www.svgrepo.com/) - огромная коллекция SVG иконок.
  - [css.gg](https://css.gg/icons) - ещё одна коллекция SVG иконок.

### Images
 - [jpeg.io](https://www.jpeg.io/) - сайт, преобразующий изображения в [progressive jpeg](https://timeweb.com/ru/blog/authors/space-police/articles/chto-takoe-progressive-jpeg/?ysclid=mi51kpc92e634380426).
 - [squoosh](https://squoosh.app/) - ресурс для оптимизации изображений

### Favicon
 - [RealFaviconGenerator](https://realfavicongenerator.net/) - можно генерировать фавиконки для сайта, для всех браузеров и устройств.

### Fonts
 - [Transfonter](https://transfonter.org/) - онлайн конвертер шрифтов.

### Other
 - [XPaste](https://xpaste.pro/) - можно вставить кусок кода, текста или другую информацию и получить сгенерированную ссылку для передачи другому человеку.
